## 4. 원본은 어디 있나


corpus 는 **남의 저작물이라 저장소에 올리지 않습니다** (`.gitignore`).
없어졌으면 다시 모읍니다.

```bash
node extract.mjs blogId/postId       # 한 편

```

평균값보다 그 자리의 실물이 정확합니다.
