## 1. 글 한 편의 뼈대

174건 구조를 기호로 찍어보면 리듬이 보입니다.
(`T`문단 `I`이미지 `H`소제목 `B`표 `-`구분선)

```
ITTHHTITTTTTTTHTTITHTTTTTTIHTTHIHTTTTTHTIHTTTTITHTTTT
└ 이미지로 열고 → 도입 두 문단 → 소제목 → 문단 5~8개 → 이미지 → 다음 소제목 …
```

**표준 뼈대**

| 순서 | 무엇 | 분량 |
|---|---|---|
| 1 | 대표 이미지 | 1장 |
| 2 | 도입 | 2~3문단 (아래 2번 참고) |
| 3 | 목차 *(선택)* | `[목차]` + 소제목 나열 — 긴 글일수록 효과 |
| 4 | **본론** — 소제목 하나 + 문단 4~8개 + 이미지 1~2장 | **이 묶음을 5~6회 반복** |
| 5 | 표 | 1~2개 (수치·비교·요건 정리) |
| 6 | 마무리 | 요약 2문단 + CTA 1문단 |
| 7 | 출처·면책 | 1문단 |
| 8 | 해시태그 | 10~15개 |

**지켜야 할 수치** (174건 중앙값)

- 전체 **2,800자** 내외 — 2,300 밑이면 얕아 보이고 3,600 넘으면 이탈합니다
- **이미지 20장** — 1000자당 9.5장, 대략 **100자마다 시각 요소 하나**
- **소제목 6개** — 500자마다 하나씩 끊습니다
- **문단은 3~5줄.** 그 이상 붙이면 모바일에서 벽처럼 보입니다

> 이미지 20장이 부담이면 카드뉴스 파이프라인(`studio/카드뉴스/cardnews-white`)에서
> 한 세트(4~6장)씩 뽑아 소제목마다 끼웁니다. 세 세트면 요건이 거의 채워집니다.

## 2. 도입 — 6가지 중에 고릅니다

상위 글의 첫 문단은 이 여섯 갈래로 나뉩니다.

| 유형 | 실제 사례 | 언제 쓰나 |
|---|---|---|
| **질문형** | "직원 채용할 때 가장 먼저 챙겨야 할 서류는 무엇일까요?" | 기본값. 어디에나 맞습니다 |
| **공감형** | "상사의 언행 때문에 반복적으로 불편함을 느낀 경험이 있으신가요?" | 당사자의 고통이 있는 주제 |
| **선언형** | "벤처기업 인증을 받으면 받을 수 있는 세제혜택을 총정리합니다" | 정리·나열형 글 |
| **통계형** | "대한상의 2024년 조사에 따르면 첨단기업의 53.7%가…" | 신뢰가 필요한 주제. 출처 필수 |
| **정의형** | "전자상거래법위반고소는 …을 위반한 행위에 형사책임을 묻는 것입니다" | 용어부터 낯선 주제 |
| **판례형** | "(광주지법 목포지원 2025. 11. 4. 선고 2025가합10102)" | 사례 분석 글 |

**speciai.team 기본값은 질문형 + 공감형 조합**입니다.
중소기업 대표가 실제로 겪는 상황을 한 줄로 던지고, 법이 어떻게 정하는지로 넘어갑니다.

```
직원이 5명이 안 되는데도 연차를 줘야 하는지 헷갈리셨을 겁니다.
"우리는 해당 없다"고 넘겼다가 나중에 진정이 들어오는 경우가 적지 않습니다.
근로기준법은 이 부분을 어떻게 정하고 있을까요?
```

**쓰지 말 것** — "안녕하세요 부산세무사/김해세무사/창원세무사/대구세무사입니다" 식으로
지역명을 나열하는 인사. 상위권에 흔하지만 낡은 수법이고 브랜드를 싸구려로 만듭니다.

## 3. 소제목 — 번호형이 기본, 후킹형이 상위권

| 유형 | 사례 | 평가 |
|---|---|---|
| **번호형** | `1. 연차유급휴가란 무엇인가요?` `2. 근로기준법 적용의 특수성` | **기본값.** 가장 안정적 |
| **질문형** | `어떤 제도일까?` `2026년 기준 금액은?` | 번호형과 섞어 씁니다 |
| **후킹형** | `"기본급만 넣고 계산했다면 손해" 올바른 산정 공식과 누락 항목` | **상위권이 씁니다.** 따옴표로 오해를 먼저 던지고 정답을 뒤에 |
| **Q&A형** | `Q1. 직장 내 괴롭힘은 어떤 것을 말하나요?` | 절차·요건 설명에 강함. 1위 글이 이 형식 |
| 키워드 반복형 | `수원법인세무사, 화성법인세무사, 봉담법인세무사` | **금지.** 키워드 스터핑입니다 |

**권장 조합** — `1. 질문형` 번호 소제목 5~6개, 그중 1~2개를 후킹형으로.

## 4. 본문 서술 — 1위 글(고용노동부 공식 블로그)의 방식

가장 잘 팔린 글의 순서가 이렇습니다.

1. 독자의 상황을 질문으로 꺼낸다
2. **독자의 속마음을 따옴표로 인용한다** — "혹시 나만 예민한 걸까?"
3. **법조문을 원문 그대로 인용한다** — `근로기준법 제76조의2는 "…"라고 규정하고 있습니다`
4. 다시 질문으로 전환 — "그렇다면 어디에 어떻게 신고할 수 있을까요?"
5. **Q&A로 본론을 푼다** — Q1/A1, Q2/A2 …
6. 답변 안에서 요건을 **①②③ 번호로 쪼갠다**

**핵심은 3번입니다.** 법조문·시행령을 조번호까지 밝혀 인용하는 것.
이게 잡블로그(전체의 78%)가 못 하는 부분이고, 우리가 이길 지점입니다.

### 반드시 지킬 서술 규칙

- **조문 인용에는 조번호를 답니다** — `근로기준법 제60조`, `부가가치세법 시행령 제54조`
- **기준일을 명시합니다** — "2026년 8월 기준", "2026년 개정 반영"
- 숫자는 **표로** 뺍니다. 문장 안에 금액·요율을 늘어놓지 않습니다
- 한 문단 한 주제. 접속사로 계속 잇지 않습니다
- 단정할 수 없는 건 단정하지 않습니다 — "사안에 따라 달라질 수 있습니다"

## 5. 마무리 — 세 덩어리로 끝냅니다

상위 글 마무리에서 공통으로 나온 요소입니다.

**① 요약** — 결론을 한 번 더. 본문에 없던 얘기를 넣지 않습니다.

```
5인 미만 사업장은 근로기준법상 연차 부여 의무가 없습니다.
다만 이는 법적 최소 기준일 뿐이라, 취업규칙이나 근로계약으로 따로 정했다면 그게 우선합니다.
```

**② CTA** — 상담으로 연결합니다. 상위 글 실사례: *"상담 시 '블로그 보고 연락드린다'고 말씀해 주시면 더 원활합니다"*

```
우리 회사에 어떻게 적용되는지 헷갈리신다면 무료 컴플라이언스 진단으로 확인해 보세요.
근로계약서·취업규칙을 함께 보고 빠진 부분을 짚어드립니다.
```

**③ 출처·면책** — 법률·세무 글은 **반드시** 답니다. 상위 글이 다 답니다.

```
본 글은 2026년 8월 기준 근로기준법 및 고용노동부 자료를 바탕으로 작성했습니다.
개별 사안에 따라 판단이 달라질 수 있으므로, 실제 적용 전 전문가 확인을 권합니다.
```

**④ 해시태그** 10~15개 — 핵심어 + 변형어 + 업종어를 섞습니다.

## 6. 절대 하지 말 것

리서치에서 상위권이 쓰지만 우리는 안 쓰는 것들입니다.
단기 노출은 되지만 브랜드가 깎이고, 네이버도 점점 걸러냅니다.

- **키워드 스터핑** — 소제목·본문에 지역명이나 키워드를 반복 나열
- **지역명 인사** — "부산세무사/김해세무사/창원세무사…"
- **낡은 기준 방치** — 상위 글 상당수가 개정 전 기준입니다. 우리는 기준일을 밝힙니다
- **출처 없는 통계** — 숫자를 쓰면 출처를 답니다
- **과장 단정** — "무조건", "100% 환급" 류. 법률·세무에서 특히 위험합니다

## 7. 자동 생성에 넣을 스펙 (요약)

글 생성 시 아래를 그대로 조건으로 겁니다.

```
분량      2,800자 ±300
구성      대표이미지 → 도입 3문단 → 소제목 5~6개(각 4~8문단 + 이미지 1~2)
          → 표 1~2 → 요약 2문단 → CTA 1문단 → 출처·면책 → 해시태그 12개
도입      질문형 또는 공감형. 중소기업 대표가 겪는 상황을 한 줄로
소제목    번호형 기본, 1~2개는 따옴표 후킹형
근거      법조문은 조번호까지 인용. 기준일 명시
문체      ~합니다 / ~하세요. 한 문단 3~5줄
금지      키워드 스터핑, 지역명 인사, 출처 없는 통계, 과장 단정
제목      30~38자. 숫자 포함. 기준이 매년 바뀌는 주제면 연도 표기
```
